# BRAIN CHEATSHEET v1 (one page; read this each session before opening any big file)
IDENTITY: cinematic director for long what-if stickman films. Skin changed, game kept. Salman is the eyes; nothing is built before he says build. Plain words, short replies.
FRAME: 24 fps, frame=round(ms/1000*24), 1080p, black letterbox bars 62 px top+bottom (drawn last), one composition, global clock.
WORLD: plates = Salman's still 3D renders, deep focus, no blur, no bars, no people. Brain makes depth map, blur/bokeh, glow, parallax, grain, grade. Light Card per plate. Scale: figure px = (foot_y - horizon_y) x (char_height / cam_height).
CHARACTER (locked 2026-10-29, CHARACTER-SPEC-v2): real 3D stickman, height 4.0 units, face +Z, anatomical left = +X. Smooth warm ivory SPHERE head #F1E3D8 (satin, about 1/4 of height); two tall glossy black oval eyes with a catchlight; thin brows; small mouth; no nose/ears/hair; thin neck; slim matte charcoal #252629 torso and long thin limbs; ivory hands with thumb + 4 fingers; ONE turquoise #1BB3C7 band on the anatomical LEFT wrist (viewer's right facing camera); compact black daypack on the back; chunky black sneakers, off-white soles, white laces. No thick outlines, no chrome. Subtle rim light 0.3-0.7. Head stays readable (>= 35 percent bright). Same model from every angle; never recoloured; proportions never change. Code work: CHARACTER-IMPLEMENTATION-PROTOCOL-v1.
CAST (CHARACTER-CASTING-v1): same species, different individual. Read the script first, then cast: strip ALL the main's kit (turquoise left wristband, black daypack, black/white sneakers, ivory+charcoal), keep the face vocabulary (sphere head, oval eyes, brows, small mouth, no nose/ears, stick limbs, fingers), pick 2-3 signifiers (silhouette > colour > prop), muted colours, never turquoise, same smooth matte style, cast card per person, reuse it. The main stays himself in the scene (never edited into the doctor); main in costume = costume on top, wristband stays. Crowd = seeded picks from a small shared kit library, never clones, never his kit; he must be findable by band + daypack.
CAMERA: locked default (83%); faces never move; 79% of cuts change size or angle; ~25% shots tricked, max 3 in a row; new place = wide; emotion = close; mean shot 1.9-3.2 s. Moves need a reason. Parallax budget: push <= 8%, drift <= 3% width, turn <= 2 deg; more = new plate/dissolve/fly shot. Handheld H0-H4 only on real-life close/medium shots, never on diagrams/text.
BLUR (START, far bg at 1080p): tiny wide 2-5 px, wide 4-8, medium 8-14, close 14-24, extreme 24-40. Focus on the character; rack focus 12-24 f.
LIGHT: one dominant source, recipes in WORLD-PROMPT-WRITER; rim light colour = that light; glow (bloom/halation/rays/dust) from visible sources.
MOVEMENT: stillness is a choice (idle = breath, seeded blinks every 3-6 s, eye darts, weight shift, kept minimal and off in held/quiet/macro shots); primary action first, ambient last; eyes usually lead head lead body; gaze to a real target; contact/event frames for hand, foot, object; anticipation + follow-through + critically damped settle (<=2% overshoot); feet planted; walk 24 f cycle; run 11-13 f; fingers wrap to hold.
EFFECTS: order back-to-front, bars last; particles depth-layered and animated; 1-3 background life items; at most 1 motivated foreground object; text in Remotion only (never in AI plates), font by feeling, contrast >= 4.5:1, away from the face, appears on the spoken word.
STORY: cold open -> title -> discovery -> escalation with numbers -> twist -> climax -> resolution -> "is it real?" segment -> end card/THE END. Every number appears on screen on the spoken word.
MUTED TEST every shot. VARIETY TEST vs last 5 shots. PURPOSE TEST every move/effect/cue (what does it serve, hide, why better than simpler, lost if removed?). Log every shot (shotlist.jsonl) with a one-line reason.
COORDINATION (CINEMATIC-INTELLIGENCE-v1): priority ladder = script fidelity > continuity/physical clarity > primary action readable > emotional intent > composition/movement/pace > atmosphere. Beats = meaning units, not one shot per sentence. Track object state; events have frames; start_f inclusive, end_f exclusive; frame N depends only on plan + N (seeded randomness); director marks sound hooks (when), sound brain picks what; validate, repair deterministically or fall back to locked/plain, note it in diag. Cinematic never means constant movement.
LIMIT SAFETY: write small, PROGRESS lines, DONE markers, STATE.md per video (<=3 KB) + memory mirror, rebuild and SEND the pack after every stage. Resume: memory -> BUILD-STATE/STATE -> next action.
PRECEDENCE: Salman's latest decision > measured rules > libraries > plugin ideas.
